# Поиск вакансий на HeadHunter

Проект предоставляет инструменты для поиска, фильтрации и сохранения вакансий с платформы HeadHunter.

### Основной функционал
1. Поиск вакансий через API HeadHunter
2. Фильтрация по ключевым словам и зарплате
3. Сортировка вакансий по уровню зарплаты
4. Вывод в терминал список вакансий
5. Сохранение результатов в JSON-файл

### Установка и настройка
Для установки зависимостей и настройки проекта выполните следующие действия:

poetry install

## Запустите программу из командной строки:

-python main.py

## Классы для работы

### Модуль работы с API (`get_vacancies.py`)

#### Класс `HeadHunterAPI`
Реализует взаимодействие с API HeadHunter для получения вакансий. Наследуется от абстрактного класса `VacancyAPI`.

##### Основные возможности:
Загружает данные по 100 вакансий за запрос (максимум 20 страниц для предотвращения лимитов API).

### Модуль работы с вакансиями (`vacancy_operations.py`)

#### Класс `Vacancy`
Основной класс для представления и работы с данными вакансий.

##### Структура объекта:

class Vacancy:

        self.vacancy_id # уникальный id вакансии
        self.name # название
        self.area # город
        self.salary_from # заработная плата от
        self.url # ссылка на вакансию
        self.snippet_requirement # описание вакансии
        self.snippet_responsibility # описание вакансии

### Модуль работы с файлами (`fileworker.py`)

#### Класс `JSONSaver`
Реализация абстрактного класса `Saver` для работы с вакансиями в JSON-формате.

##### Основные возможности:
1. Сохранение вакансий с проверкой уникальности по ID
2. Чтение/удаление записей из файла
3. Автоматическая нормализация имен файлов


### Модуль вспомогательных функций (`utils.py`)

#### Основные функции обработки данных

##### 1. `clean_split_str()`
**Назначение**: Подготовка пользовательского ввода для фильтрации  
**Особенности**:
- Удаляет специальные символы
- Приводит текст к нижнему регистру
- Разделяет строку на отдельные слова

`clean_split_str("Python, Django! REST;") 
 → ["python", "django", "rest"]`

##### 2. 'sort_vacancies()'
Назначение: Сортировка вакансий по зарплате
По умолчанию сортирует по убыванию
Основана на реализации `__lt__` в классе Vacancy

`sorted_vacancies = sort_vacancies(vacancies, reverse=False)`

##### 3. filter_vacancies()
Назначение: Фильтрация по ключевым словам
Ищет совпадения в требованиях и обязанностях

Фильтрация по ["python", "postgres"]:
`filtered = filter_vacancies(vacancies, ["python", "postgres"])`


##### 4. get_vacancies_by_salary()
Назначение: Фильтрация по диапазону зарплат
Поддерживаемые форматы:
"100000" (зарплата от 100000)
"100000-150000" (диапазон)

`get_vacancies_by_salary(vacancies, "120000-180000")`

##### 5. get_top_vacancies()
Назначение: Выборка первых N вакансий
Автоматическая проверка типа параметра
